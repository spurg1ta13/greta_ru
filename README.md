# Greta Rusecke – Portfolio & Services Website

This repository contains the source code for my personal portfolio and services platform, hosted live at [gretagreta.eu](https://www.gretagreta.eu). 

The site showcases my expertise as an **ISTQB® Certified Senior QA & No-Code Engineer**, highlighting end-to-end web testing services, No-Code prototyping solutions, and a showcase of live B2B projects.

---

## 🛠 Tech Stack & Tools

* **Frontend Framework:** React + TypeScript (Vite)
* **Styling & UI:** Tailwind CSS, shadcn/ui
* **No-Code / Prototyping:** Lovable AI
* **DNS & Hosting:** Papaki / Lovable Hosting
* **Version Control:** GitHub

---

## 🚀 Key Features

* **Services Overview:** Detailed breakdown of Pre-Launch QA, No-Code Development, and Post-Launch Maintenance packages.
* **Portfolio Showcase:** Live client projects built and tested end-to-end (e.g., `lotusbloom.gr`, `cleanupskg.gr`, `devcraft.gr`).
* **Interactive UI:** Fully responsive design tested across desktop, tablet, and mobile breakpoints.
* **Direct Contact:** Integrated contact and LinkedIn channels for B2B inquiries.
